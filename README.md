# 🧮 ProCalc - Calculatrice Comptable Professionnelle

Une calculatrice web moderne et intuitive conçue spécialement pour les professionnels de la comptabilité et de la gestion financière.

## ✨ Caractéristiques

### Calculatrice Standard
- Interface intuitive avec boutons oversized
- Support complet du clavier
- Opérations mathématiques basiques (+, -, ×, ÷)
- Historique des calculs

### Outils Comptables
- **TVA**: Calcul automatique HT/TTC avec tauxs prédéfinis
- **Marge**: Analyse de marge brute, pourcentage et coefficient
- **Rabais**: Calcul des réductions et prix final

### Convertisseur Devises
- Conversion EUR vers 5 principales devises
- Taux de change inclus

### Fonctionnalités Bonus
- 📝 Historique persistant (localStorage)
- 📱 Interface responsive (desktop & mobile)
- ⌨️ Support clavier complet
- 🎨 Design moderne avec glassmorphism
- 💾 Sauvegarde automatique des calculs

## 🚀 Installation

1. Cloner le repository:
```bash
git clone https://github.com/Samuelrivaldo/calculatrice_js.git
```

2. Ouvrir `index.html` dans votre navigateur préféré

Aucune dépendance requise - Application 100% vanilla JavaScript!

## 📖 Utilisation

### Calculatrice Standard
- Cliquez sur les boutons ou utilisez le clavier
- Utilisez `C` ou `Échap` pour effacer
- Appuyez sur `Entrée` ou `=` pour calculer
- Utilisez `Retour arrière` pour supprimer le dernier chiffre

### Calculatrice TVA
1. Entrez le montant HT
2. Sélectionnez le taux TVA
3. Le montant TTC s'affiche automatiquement

### Calculatrice Marge
1. Entrez le prix d'achat
2. Entrez le prix de vente
3. Consultez la marge brute, le pourcentage et le coefficient

### Calculatrice Rabais
1. Entrez le montant original
2. Entrez le taux de rabais en %
3. Consultez le prix final

### Convertisseur Devises
1. Entrez un montant en EUR
2. Sélectionnez la devise cible
3. Le résultat s'affiche automatiquement

Tous vos calculs sont automatiquement sauvegardés dans l'historique:
- Jusqu'à 20 derniers calculs conservés
- Affiche l'opération et le résultat
- Horodatage automatique
- Bouton pour effacer tout l'historique

## ⌨️ Raccourcis Clavier

| Touche | Action |
|--------|--------|
| 0-9 | Entrer un chiffre |
| `+` `-` `*` `/` | Opérateurs |
| `.` | Virgule/Point décimal |
| `Entrée` | Calculer |
| `Retour arrière` | Supprimer le dernier chiffre |
| `Échap` | Effacer tout |
